# 液态玻璃 UI 重构设计文档（Liquid Glass UI）

日期：2026-08-14
项目：AuraKernel / YeQiuLauncher（`com.aa.Aurakernel`）
状态：已确认（用户逐节审阅通过，HTML 交互原型已验收）

## 1. 背景与目标

当前 UI 为白底绿色系、渐变胶囊导航栏、scaleX 进度条，风格偏传统。用户希望整体换为**液态玻璃（Liquid Glass）风格**：

- 全应用背景为**动态流体**（缓慢流动的波浪，可换色系/壁纸图）
- Tab 栏为 **LiquidTab**（液态指示球，点击甩动、连点搅动、弹簧回弹）
- 进度条为**流体效果**（波浪填充，进度变化时拉伸涌起回弹，可拖动）
- 全局**无缝换肤**（3 色系 × 明暗自动跟随系统）
- 强交互：卡片按压回弹、按钮弹性、页面切换液态过渡

## 2. 需求确认记录

| # | 问题 | 用户选择 |
|---|---|---|
| 1 | 背景含义 | A：动态流体背景（缓慢流动，可换颜色/壁纸图） |
| 2 | 色系 | C：2~3 套预设色系可切换（绿 / 青蓝 / 紫粉） |
| 3 | 交互范围 | C：极致体验（连点搅动、进度条拖动回弹、下拉拉扯感） |
| 4 | 暗色模式 | B：跟随系统自动切换暗色配色 |
| 5 | 壁纸来源 | C：内置几款 + 支持从相册选择 |

## 3. 方案选择

**方案 A：全自绘 Canvas 流体引擎**（已确认）

理由：
- 与现有代码风格一致（CapsuleNavBar 本就是自绘 View），零第三方依赖（项目离线构建，依赖拉取有风险）
- 流体效果（波浪形变、搅动、拖拽回弹）只有自绘可控
- 被否方案：B 轻量组合式（效果"像液体"而非"是液体"）；C 引入 Lottie（液态交互做不了 + 依赖风险）

## 4. 总体架构

新增组件（`com.aa.Aurakernel.ui` 包）：

```
ui/
├── LiquidBackgroundView     全屏流体背景（壁纸/色系/明暗，波浪持续流动）
├── LiquidTabBar             液态 Tab 栏（改造现有 CapsuleNavBar）
├── FluidProgressView        流体进度条（替换现有 3 处进度）
├── GlassCard                玻璃卡片容器（替换现有卡片圆角背景）
├── GlassButton              玻璃按钮（按压弹性）
├── core/
│   ├── ThemeManager         6 套主题 token + 系统深色监听 + SharedPreferences 持久化
│   ├── FluidPhysics         弹簧阻尼 / 波浪 / 能量注入数学库
│   └── WallpaperStore       内置壁纸资源 + 相册选择（Photo Picker 免权限）+ 模糊预处理
```

改造原则：
- **MainActivity 只动视觉层**：页面内容构建（公告、卡密、驱动列表、物资列表）数据流零改动
- 现有硬编码颜色（MAIN_GREEN、白色背景等）收敛到 ThemeManager
- 驱动下载 `updateDownloadProgress` 回调不变，内部实现换成 FluidProgressView.setProgress()
- 长按拖拽切页保留，页面过渡替换为液态过渡动画

## 5. 动效规范

| 动效 | 实现 | 参数 |
|---|---|---|
| 背景流动 | 3 层正弦波叠加 | 振幅 26/17/8，频率 0.0085/0.014/0.022，速度递增，相位每帧推进，无缝循环 |
| Tab 甩动 | 阻尼弹簧 x'' = -320x - 26x' | 点击注入初速 v += Δx×6 |
| 连点搅动 | 能量值累加（封顶 1.6）叠加抖动 sin(t)×E×3.2，能量每帧衰减 0.018 | 液体球沿速度方向拉伸 scale(1.85, 0.15) |
| 进度条涌起 | 进度变化瞬间波浪流速 ×4.7（0.55s）回落 | 拖动松手同样触发 |
| 页面切换 | 淡入 + 上移 10px，380ms | — |
| 涟漪 | 点击处圆形扩散 0.7s | — |
| 帧率策略 | 前台 60fps；失焦暂停；静止 2s 降 30fps | 省电 |

## 6. 主题 Token（6 套）

```
Theme { w1, w2, w3(波浪渐变), acc(强调色), text, sub, glass(玻璃底), border(高光边) }
```

| 色系 | 浅色（w1→w2→w3 / acc） | 深色（w1→w2→w3 / acc） |
|---|---|---|
| 绿 | #1E8A4F→#35B76A→#5FDB8F / #23A55A | #0B2E1B→#14532D→#1E8A4F / #35C77B |
| 青蓝 | #0B7FA3→#12A8D1→#4FD4F2 / #0FA3D8 | #06242F→#0B3A4A→#0B7FA3 / #18BCE8 |
| 紫粉 | #8B3FBF→#B14FE0→#E27BF0 / #A84FE0 | #240A38→#3B1457→#8B3FBF / #C06AF0 |

- 玻璃底：浅色 `rgba(255,255,255,.55)`，深色 `rgba(12,20,26,.5)`；高光边 1px 随明暗切换
- 切换动画：颜色 ArgbEvaluator 插值 600ms，广播通知全部组件刷新
- 明暗：UiModeManager 深色广播自动切换；用户手动选择覆盖（SharedPreferences）

## 7. 玻璃材质规格

- 卡片：半透明底 + `RenderEffect` 实时模糊（API 31+）/ 预模糊位图（API 26–30）+ 1px 白高光描边 + 内侧柔和阴影 + 圆角 24dp + 顶部内高光线
- 按钮：渐变底 + 高光 + 按压 scale 0.93 回弹（cubic-bezier(.34,1.8,.64,1)）
- 文字对比度：正文用 text token，浅色模式下保证 WCAG AA（深色文字压浅玻璃）

## 8. 性能与兼容

- 模糊：API 31+ `RenderEffect.createBlurEffect`；API 26–30 降级预模糊位图 + 半透明叠加（背景本就是动态波浪，差异不易察觉）
- 绘制预算：背景波浪步长 4px；光斑/气泡静态 Drawable；CLIP_TO_LAYER 限制绘制区域
- 壁纸：`ActivityResultContracts.PickVisualMedia`（Photo Picker 免权限）；选图降采样 + 高斯模糊生成壁纸层并缓存
- 帧率自适应：连续 3 帧 > 20ms 自动降波浪层数 3→2，恢复后回升

## 9. 错误处理

- 壁纸加载失败：回退内置壁纸 + Toast「图片加载失败，已使用默认壁纸」
- 下载进行中禁止拖动进度条（进度回调优先）
- 主题 token 缺失：ThemeManager 兜底返回绿色浅色默认值

2. 拖动进度条与真实下载进度不冲突（下载中禁拖）

## 11. 范围外（YAGNI）

- 不引入任何第三方依赖
- 不做 Compose/XML 迁移
- 不做设置云同步
- 不做动态壁纸服务（Live Wallpaper）——仅应用内流体背景
